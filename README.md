# Uddyog-Saarthi

Uddyog-Saarthi is a website that provides educational courses as well as job notifications specifically designed for physically handicapped persons. This platform helps physically disabled individuals easily find job postings made by the admin and access educational resources to enhance their skills and employability.

## Features

- User-friendly interface tailored for physically handicapped users.
- Educational courses to improve skills and knowledge.
- Job notifications and listings posted by the admin.
- Separate sections for students and admin management.
- Secure login and registration system.
- Admin panel to manage courses, job postings, and users.
- Support for password recovery and profile management.

## Installation

To set up the Uddyog-Saarthi website locally, follow these steps:

1. Ensure you have a web server with PHP and MySQL installed (e.g., XAMPP).
2. Clone or download the project files into your web server's root directory (e.g., `htdocs` for XAMPP).
3. Import the database schema from the `sql/placement.sql` file into your MySQL server.
4. Configure the database connection settings in the appropriate configuration files (e.g., `includes/db.inc.php`).
5. Start your web server and navigate to `http://localhost/Uddyog-Saarthi` in your browser.

## Usage

- Register as a student or admin to access respective features.
- Students can browse and apply for jobs, view courses, and manage their profiles.
- Admins can add and manage job postings, courses, and view student applications.
- Use the password recovery feature if you forget your login credentials.

## Technologies Used

- PHP for server-side scripting.
- MySQL for database management.
- HTML, CSS, and JavaScript for frontend development.
- XAMPP as the local development environment.
